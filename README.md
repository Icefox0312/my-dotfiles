# ❄️ Icefox's Dotfiles

My personal dotfiles for Arch Linux, featuring a dynamic tiling Wayland setup using Hyprland.

## 🌟 Features
* **OS:** Arch Linux
* **Window Manager:** Hyprland (Wayland)
* **Shell:** Fish + Starship prompt
* **Terminal:** Kitty
* **Bar/Widgets:** Waybar / Quickshell
* **Launcher:** Rofi
* **System Monitor:** Btop
* **Visuals:** Pywal (Dynamic colors) & Cava (Audio visualizer)

## 📁 Repository Structure
* `.config/`: Application configuration files.
* `bin/`: Custom shell scripts (wallpapers, environments, etc.).
